## Portfolio

The site includes an introduction, skills, featured projects, and contact
information. Its static files are `index.html`, `styles.css`, `script.js`,
`data.js`, and `profile.jpg`.

### Run locally

With Node.js installed, run:

```powershell
node server.js
```

Then open http://localhost:3000/.

## Update content

Use the in-browser editor to preview changes in your current browser. To publish
changes, export `data.js`, replace the project's copy, and push the update to
GitHub. See [HOW_TO_UPDATE.md](./HOW_TO_UPDATE.md) for details.
